Projeto ISO 9001:2015 para Software

Disciplina de Qualidade de Software. Para cada seção da ABNT NBR ISO 9001:2015, proponha soluções, práticas e artefatos gerais que uma organização de software poderia adotar para atender aos requisitos. Escreva com suas próprias palavras: o sistema sinaliza trechos colados e, ao enviar, gera um PDF protegido com código de verificação, envie esse PDF no SIGAA.

Como funciona o projeto
  1. Leia a seção correspondente da norma e a tarefa descrita em cada quadro.
  2. Escreva possíveis soluções gerais para atender aos requisitos, valendo para qualquer empresa de software (processos, artefatos, ferramentas, métricas, responsáveis).
  3. Sempre que possível, cite o número da subseção (ex.: 8.3.4) e a evidência que um auditor pediria.
  4. Cores dos quadros seguem o ciclo PDCA: azul = Planejar (0–7), verde = Fazer (8), laranja = Verificar (9), vermelho = Agir (10).
